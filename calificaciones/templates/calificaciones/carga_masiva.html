Reglas de validación

  • Delimitador ;, codificación UTF-8 (con o sin BOM) o Latin-1.
  • Decimales con punto o coma; se cuantizan a 8 decimales con ROUND_HALF_UP.
  • Fecha estricta DD-MM-AAAA; secuencia de evento > 10000.
    • {% if es_monto %}
  • Montos >= 0; B = VALOR_HISTORICO si es positivo, si no la suma de montos.
  • Tolerancia de redondeo: exceso de hasta 0.00000005 solo si VALOR_HISTORICO = 0.
    • {% else %}
  • Cada factor en [0.00000000, 1.00000000]; suma F8–F37 <= 1.00000000.
    • {% endif %}
  • Se rechazan duplicados dentro del archivo y contra la base de datos.
